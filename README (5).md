# docs/

Documentation du projet : comptes rendus de séance, cadre RGPD, guide d'installation, rapport de sécurité.

## Cadre d'utilisation (à compléter par Kiliann)

- Le proxy ne tourne que sur des PC de test appartenant à l'équipe.
- Seules des données inventées sont utilisées pendant les tests et la démo.
- Aucun trafic d'une personne extérieure à l'équipe n'est intercepté.
- Les événements enregistrés ne contiennent jamais la donnée sensible en clair (elle est masquée avant stockage).
